Security foundations

Twenty labs completed on Hack The Box before I built anything on AWS. Each one documents the attack, the evidence, and the detection signal that catches it.

  • Wireshark
  • Active Directory
  • Detection
  • Windows hardening
  • PCAP analysis
Why this belongs in a cloud portfolio: most cloud incidents start with a stolen credential or an over-broad permission. Having captured a Kerberoasting request and traced a DNS tunnel byte by byte changes how you write an IAM policy, scope an OIDC trust relationship, or segment a VPC. The projects elsewhere on this site apply that mindset to infrastructure.
