Learning path

From console clicks to GitOps in three months

These are self-directed projects, built deliberately in order: do it by hand first, then automate it, then make Git the source of truth.

  1. JUL 2026 · Projects 1–2

    Core networking and compute by hand

    S3 hosting, then a custom VPC with an internet gateway, route table and an EC2 web server.

  2. JUL 2026 · Projects 3–4

    Everything from the CLI

    Serverless API and a Fargate container, scripted with the AWS CLI to understand the underlying APIs and IAM before abstracting them away.

  3. JUL 2026 · Project 5

    Infrastructure as Code with Terraform

    A multi-AZ load-balanced web tier, declared and applied as code.

  4. AUG 2026 · Project 6

    Automated delivery with keyless auth

    A full CI/CD pipeline to ECS Fargate using OIDC, scanning and monitoring.

  5. SEP 2026 · Project 7

    GitOps on Kubernetes

    EKS and ArgoCD, with the cluster state owned by Git rather than by the pipeline.
